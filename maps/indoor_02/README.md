## 导航到抓取交接

`run_indoor_recorded_route.sh` 先以精细容差到达抓取预停点（记录点 1：位置
`±0.08 m`、航向 `±0.08 rad`，约 `±4.6°`）。随后保持记录的平行朝向，以
`0.12 m/s` 直线低速前进约 `0.84 m` 至抓取点（记录点 2），同样以
`±0.08 m`、`±0.08 rad` 判定到位。

最终直线段不使用 Nav2 局部代价地图来规划，因此不会在抓取工位前临时转向；但前方
窄区域的点云急停仍然启用（距离小于 `0.35 m` 时停车）。只有预停点和抓取点都成功
到位时，才会调用机械臂仓库中的
`scripts/run_navigation_grasp_handoff.sh`，由 `/grasp_pipeline` 接管目标细扫和抓取。

可显式指定六种目录目标：

```bash
ros2 run scout_navigation_bringup run_indoor_recorded_route.sh red_block
```

不传目标时使用 Dashboard 当前选中的 `target_item_id`。导航开始前会预检抓取栈、
`/base_scan_controller/move_relative` 和 `/odom`；任何一项不就绪都会在底盘移动前退出。

## 普通导航失败后的脱困

每次收到导航目标后，行为树会先忽略局部代价地图，以 `0.08 m/s` 累计低速前进
`1.5 s`，再无缝切换至普通 Nav2。正前方 `0.45 m × 0.36 m` 的雷达窄区域仍作为
人员急停区：有人时暂停，离开后继续累计剩余的低速前进时间；雷达点云未就绪时也不会
启动。

普通导航或精确预停点导航失败后，`ScoutSlowForward` 恢复插件会通过
`/cmd_vel_nav` 以 `0.08 m/s` 前进 `1.5 s`，随后不发送停车指令，直接把运动控制交给
Nav2 重新规划原目标。速度平滑器会在重新规划期间维持最后的低速指令，普通控制器的
新指令到达后直接接管。行为树最多进行 4 次导航尝试；取消任务时才会停止。
