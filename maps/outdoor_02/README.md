## 当前自动测试路线

自动路线先经过“目标点1前置点”、目标点1，再直接前往“回原点1”和“回原点2”。
小路、三处大柱子和出小路（点2至6）当前不参与自动路线。到达“回原点2”（点8）后，
执行第一轮抓取—放置流程（点9至15）；第一轮到达放置点后，紧接着再完整执行第二轮
点9至15。

通用 `safe_startup_forward.py` 可用于沿当前车头以 `0.50 m/s` 前进 `2.0 m`，且带前方
`0.80 m`、宽 `0.70 m` 的雷达急停保护。当前 outdoor_02 路线**未启用**该步骤：启动时
直接进行整条路线的无运动规划预检，预检成功才允许 Nav2 接管；预检失败时保持停车等待。

每轮抓取—放置流程均为：

`待抓取点 → 抓取点 → 抓取/放置后行动一 → 抓取/放置后行动二 →
抓取/放置后行动三 → 放置预停点 → 放置点`

每个导航目标失败时会等待2秒并重试同一点；两轮均完成后，节点保持运行，只有手动
按 `Ctrl+C` 才会终止。当前任务脚本还包含红旗启动与机械臂交接逻辑：若相应服务
未启动，脚本会保持等待而不会跳过抓取、放置任务。

## 连续通过与必要停车

普通路段不会再为每个中间记录点结束一次导航任务：目标点1前置点与点1至8使用一次连续多点导航，
每轮中的点11至13也使用一次连续多点导航。因此这些段落中间不会因到达目标点而
额外发送停车速度。

点9（待抓取点）和点14（放置预停点）必须停车以完成高精度位置、朝向对齐；点10
和点15是抓取、放置位置，若该任务脚本启用了机械臂交接，也必须停车后才可交接。
这些停车是任务要求，不是普通点之间的无效等待。

“待抓取点”（点9）与“放置预停点”（点14）在每一轮均使用高精度导航：位置容差
`0.10 m`、朝向容差 `0.12 rad`（约 6.9°）。其余点使用普通导航容差。

从待抓取点到抓取点（9→10）、从放置预停点到放置点（14→15）复用已有的
`dock_to_recorded_point3.py` 慢速停车程序：先由 Nav2 高精度到达预停点，再按目标
朝向以 `0.15 m/s` 低速直行进入最终点。末段不采用局部代价地图，避免局部点云膨胀层
阻塞已验证的靠近路线；但保留前方 `0.45 m`、宽 `0.32 m` 的窄区域点云急停保护。
若定位暂时不稳或该窄区域检测到物体，路线会等待后从预停点自动重试，不会自行退出。

普通点使用通过而非停车的容差：位置 `0.60 m`、朝向 `1.20 rad`（约 69°）；连续路线
也会在距已通过点 `0.60 m` 时立刻移除该点。这样临时避障后会继续朝下一个点走，不会
再为了回到普通点的精确位置或朝向而绕圈。点9、点14的高精度预停，以及9→10、14→15
的慢速精细停车完全不受影响。

普通点的录制朝向不会再交给状态格点规划器；路线会自动将每个普通点朝向设为指向下一点
的路径切线，避免为了匹配旧车头方向出现先右后左的大弯。预停点、抓取点和放置点仍使用
原始记录朝向。

## 高速避障配置

室外巡航上限为 `0.70 m/s`。全局规划使用平滑后的状态格点路径，并偏向更短的有效
路线；局部控制以 `15 Hz` 更新。为避免直路上左右试探，MPPI 的角速度采样标准差为
`0.08 rad/s`，最大角速度及速度平滑器角速度上限均为 `0.40 rad/s`；高速时优先减速
后转向，而不是高速左右摆动。静态地图边界的局部/全局膨胀层分别为
`0.42 m`、`0.45 m`，让路线优先保持在道路中部；实时雷达障碍膨胀层为 `0.75 m`，
检测范围为 `5 m`。速度平滑器的前进加速度为 `0.85 m/s²`、制动减速度为
`1.70 m/s²`。雷达实时障碍点在不再观测到后最多保留 `0.25 s`。

MPPI 会在距最终目标 `5 m` 内更积极地缩短目标距离，并跟随更靠前的路径点；因此无障碍
直路会优先接近 `0.70 m/s` 巡航，而不是长期停留在约 `0.30 m/s`。碰撞代价、膨胀层和
最大转速限制保持不变。
